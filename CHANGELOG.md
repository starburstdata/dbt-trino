## dbt-trino 1.11.0 - October 23, 2026
### Breaking Changes
- Support dbt-core 1.11 and drop support for Python 3.9 ([#549](https://github.com/starburstdata/dbt-trino/pull/549))
### Features
- Support `on_table_exists='replace'` for seeds, rebuilding them with `CREATE OR REPLACE TABLE` instead of dropping the existing table ([#547](https://github.com/starburstdata/dbt-trino/issues/547), [#548](https://github.com/starburstdata/dbt-trino/pull/548))
- Support scalar SQL user-defined functions ([#550](https://github.com/starburstdata/dbt-trino/pull/550))
### Fixes
- Stop unit test string fixture values from being truncated to the upstream column's varchar(n) length ([#549](https://github.com/starburstdata/dbt-trino/pull/549))
- Warn when persist_docs documents columns that don't exist in the database, and match documented column names case-insensitively so quoted mixed-case columns get their comments ([#549](https://github.com/starburstdata/dbt-trino/pull/549))
### Under the Hood
- Replace deprecated `--models` flag and top-level generic test arguments in tests, and add the dbt-tests-adapter 1.20 snapshot hard_deletes and clone grants test suites ([#549](https://github.com/starburstdata/dbt-trino/pull/549))
