## dbt-trino 1.10.3 - July 27, 2026
### Features
- Extend `persist_docs` to sync model and column descriptions to Starburst's Data Discovery catalog, not just to SQL `COMMENT ON` statements. When a connection sets `starburst_url` (along with `starburst_client_id` and `starburst_secret_key`), enabling `persist_docs` also writes those descriptions to Starburst's catalog explorer through its public REST API. Column descriptions are sent in batches, with the batch size controlled by `starburst_max_column_batch_size` (default 100). Use `starburst_metadata_failure_strategy` to control how API errors are handled: `continue_on_error` (the default) logs a warning and carries on, while `fail_fast` aborts the run. To keep secrets out of `profiles.yml`, source the credentials from environment variables, for example `{{ env_var('DBT_ENV_SECRET_STARBURST_CLIENT_ID') }}` and `{{ env_var('DBT_ENV_SECRET_STARBURST_SECRET_KEY') }}`. Projects that do not set `starburst_url` are unaffected. ([#520](https://github.com/starburstdata/dbt-trino/pull/520))
