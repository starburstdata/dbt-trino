## dbt-trino 1.10.4 - September 16, 2026
### Features
- Support `client_tags` and `http_headers` as model configs, overriding the profile's values for the statements a model runs. Trino routers pick a cluster per statement from the request headers, so a single run can send individual models to different clusters - for example a large incremental model to a fault-tolerant cluster while the rest of the project stays on the default one. With Starburst Galaxy, connect to the account's routing endpoint and add a routing rule per tag; note that a query matching no rule is rejected rather than routed to a default cluster. ([#525](https://github.com/starburstdata/dbt-trino/issues/525), [#526](https://github.com/starburstdata/dbt-trino/pull/526))
### Fixes
- Fix `with_starburst_fields` dropping a decorated class's own annotations (e.g. `session_properties`) on Python 3.14, where `cls.__dict__` no longer eagerly contains an `__annotations__` entry under PEP 649/749 deferred evaluation. This previously raised `TypeError: '...' is a field but has no type annotation` on import for every credentials class, breaking `dbt-trino` outright on 3.14. ([#527](https://github.com/starburstdata/dbt-trino/pull/527))
- Pull minio images from quay.io instead of Docker Hub ([#528](https://github.com/starburstdata/dbt-trino/pull/528))
